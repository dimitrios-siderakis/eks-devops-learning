## When to Use kubernetes.io vs Other Sources

| Question type | Best source |
|---|---|
| "What does this field do exactly?" | kubernetes.io API reference |
| "How does this concept work?" | kubernetes.io Concepts |
| "Step-by-step hands-on" | KodeKloud labs |
| "Real-world patterns and war stories" | Nigel Poulton book |
| "EKS-specific behaviour" | AWS docs / EKS user guide |
